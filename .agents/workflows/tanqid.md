# Tanqid (Code Critique) Workflow
1. Inspect the provided git diff or codebase slice thoroughly.
2. Give zero praise and write no application code.
3. Identify and rank the top 5 problems found in the diff.
4. Focus critique strictly on: security vulnerabilities, N+1 query patterns, spec mismatches, test coverage gaps, and scope drift.
5. Format findings as concise bullet points: Problem / Impact / Recommendation.
