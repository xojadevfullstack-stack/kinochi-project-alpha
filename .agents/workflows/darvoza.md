# Darvoza (Gatekeeper) Workflow
1. Review the completed diff, test results, and `STATE.md` update.
2. Formulate exactly 3 critical questions testing understanding of the diff (architecture, edge cases, failure modes).
3. Present the 3 questions to the user.
4. Evaluate the user's responses against the code reality.
5. Do not mark the slice or branch ready for merge/deploy until the user answers all 3 questions correctly.
